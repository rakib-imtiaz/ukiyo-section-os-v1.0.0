# Changelog

## 1.0.0 — Production foundation

- Added multi-store Shopify OAuth.
- Added encrypted expiring offline tokens with automatic refresh-token rotation.
- Added PostgreSQL migrations and development memory mode.
- Added saved projects, immutable versions, deployment snapshots, and rollback.
- Added secure API-key management, authenticated REST API, rate limiting, and Streamable HTTP MCP.
- Added Shopify app-uninstall and mandatory compliance webhooks.
- Added optional Shopify recurring billing configuration.
- Added production Docker image, environment validation, security headers, and audit events.
- Expanded the interface with Projects, Deployments, Connections, API keys, and deployment history.
- Added launch, deployment, privacy, terms, and Shopify submission documentation.
- Expanded automated verification to compiler, security, repository, and MCP suites.

## 0.1.0 — Working MVP

- Added the visual cinematic hero builder.
- Added the Section OS design contract and native Shopify compiler.
- Added Liquid, CSS, JavaScript, schema, preview, validation, and ZIP export.

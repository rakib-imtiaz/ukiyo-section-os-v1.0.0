1 The AI assistant was blocked by a safety check

Solved

What went wrong

The first version used an AI assistant to click through Shopify and fetch the store's secret connection keys. A built-in safety check saw an AI handling secret keys and stopped it before it did anything. Nothing was created and nothing was harmed, but the setup could not go ahead.

What we did

We switched to a fixed, step-by-step script for the Shopify part. It does the same clicks every time, with no AI involved. That means it's:

  • much faster: seconds instead of minutes;
  • free to run: no AI usage cost;
  • safer: no AI ever sees the secret keys.

The AI version stays available as a backup button.

Result

The script set up the ECO ELI store and its connection end to end.

2 Google refused to sign in inside the automated window

Solved

What went wrong

Google does not allow signing in inside a browser window that a program is controlling. It shows "This browser or app may not be secure", even for the account owner.

What we did

The one-time sign-in now happens in a normal browser window that ThemeBot opens but does not control. You sign in the usual way (Google works), close the window, and ThemeBot reuses that saved sign-in. Your everyday Chrome stays open the whole time.

Result

Signed in once, and every run since has gone straight through.

3 Shopify had quietly changed its own pages

Solved

What went wrong

Shopify had renamed and moved things since the script was first written. "Create store" is now "Create new store". The "Create app" button works differently. The store-name setting moved to its own page. The script was looking for the old versions and stopped.

What we did

We walked through Shopify's real pages together, one screen at a time, and updated the script to match. It now:

  • goes straight to the right page instead of clicking through menus;
  • recognises the different wordings Shopify uses;
  • never touches any other store on the account.

Result

Store created in about 10 seconds, and the connection app created and installed on the first try after the update.

4 The new store kept Shopify's default name, "My Store"

Solved

What went wrong

Shopify names every new store "My Store". ThemeBot tried to rename it, but the setting had moved (see obstacle 3), so the new store kept the default name.

What we did

We found the store-name page, pointed ThemeBot straight at it, and renamed the ECO ELI store.

Result

The store is now called ECO ELI. Every future store gets its proper name automatically.

5 A long build was stopped as "stuck" while it was actually working

Fix in place, confirming on next run

What went wrong

ThemeBot has a safety timer that stops a build if it shows no sign of life for 20 minutes. The build works quietly and only reported progress at the very end, so after 20 minutes the timer stopped it, even though it had already written over 100 theme files.

What we did

  • Builds now report every step as they go, so the timer can see they are alive.
  • A new Live activity panel, with an on/off switch, shows exactly what the build is doing: every file it writes and every step it takes.

Result

The fix is in place. The ECO ELI build will be re-run to finish, and it continues from the files already written.

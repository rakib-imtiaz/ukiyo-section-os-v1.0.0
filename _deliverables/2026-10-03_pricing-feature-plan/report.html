4 · What makes the agency version premium

Why agencies pay more for desktop

The web app sells builds. The desktop app sells a production line the agency owns.

Unlimited buildsRuns on their own AI plan, so there are no per-build fees. The more stores they build, the cheaper each one gets.
Automatic store setupCreates the Shopify store, the app and its keys in their own browser. Web users have to do this themselves.
Several builds at onceRun 2–4 client stores at the same time on their own computers, with no shared queue.
Client work stays in-houseSource sites, themes and reports stay on the agency's computers, which agencies with strict clients need.
Built for teamsSeats per person, client history across every project, and cheap extra seats.
White-label client reportsBefore/after PDF reports with the agency's own logo for their clients. PLANNED
Early accessNew features reach the agency channel first, and founding agencies help shape the roadmap. PLANNED
They own the toolA one-time licence keeps working, even if they stop paying for updates.
Break-even for an agency: at 10 stores a month the web Agency plan costs about $6,000 a year. A desktop licence is $2,495 once (+$795 a year from year two): it pays for itself in about 5 months, or about 8 counting their own AI plan.

6 · Keeping both versions up to date

How we control versions

One engine and one version number for both products. Every update is tested once, then reaches desktop and web together.

Build & testone engine, e.g. v1.4
→
Early accessfounding agencies first
→
Stableeveryone, a few days later
→
Desktopdownloads quietly, installs on restart
Weblive for everyone at once
Updates follow the licenceDesktop updates are included while the yearly plan is active. If it lapses, the app keeps working on the last version they had.
Safety updates for everyoneWhen Shopify or the AI provider changes something, we can require a minimum version so no one runs a build that would fail.
One code base, plan switchesBoth versions share the same code; each plan simply switches features on or off. No separate copies to maintain.
Web rolls out graduallyWe can send a new web version to a small share of users first, then everyone, and undo it in minutes if needed.
The engine improves for allFrom January the build method runs on our server, so improvements reach every desktop and web user at once, without an app update.
Clear release notesEvery version gets a short "what's new" inside the app and a changelog page.

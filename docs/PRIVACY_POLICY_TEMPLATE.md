## Information processed

The service processes the connected store's `myshopify.com` domain, encrypted Shopify access credentials, section project manifests, generated theme files, deployment history, API-key metadata, and operational audit events. API-key secrets are shown once and stored only as one-way hashes.

The app does not request customer, order, payment, or checkout data. Section content supplied by the merchant is processed only to generate theme files and previews.

## How information is used

Information is used to authenticate stores, save section projects and versions, compile Shopify theme files, deploy merchant-approved changes to unpublished themes, provide rollback, secure external platform connections, prevent abuse, and support the service.

## Storage and security

Shopify access and refresh tokens are encrypted at rest. Browser sessions use signed, HTTP-only cookies. Production traffic uses HTTPS. Access is limited to systems and personnel required to operate the service.
